# Fase 3 — XP Investimentos

Os investimentos vêm **só do Open Finance**, pela Pluggy. Nenhuma posição, quantidade, preço médio ou saldo fica escrito no código.

```
Santander (PLUGGY_SANTANDER_ITEM_ID) ─┐
XP        (PLUGGY_XP_ITEM_ID)        ─┴─▶ GET /investments?itemId=…  ─▶ posições
                                                         │
                                  ações (EQUITY) ────────┴─▶ cotação atual brapi.dev
```

## 1. Conectar a XP

1. No **meu.pluggy.ai** → "Nova conexão" → **XP Investimentos** via Open Finance, autorizando **investimentos**.
2. No Dashboard da Pluggy → aplicação `mymoney` → **▷ (demo)** → "Conectar Conta" → conector **MeuPluggy** → autorize a XP.
3. Copie o Item ID (menu ⋮ → "Copiar Item ID") e preencha `PLUGGY_XP_ITEM_ID` no `.env.local`.
4. Rode `npm run check:pluggy` e confira a lista de investimentos da XP.

Enquanto a XP não estiver conectada, a tela de Investimentos mostra só o que o Santander informa e um aviso para conectar a XP.

## 2. Como cada investimento é classificado

| Pluggy `type`/`subtype` | Classe no app |
|---|---|
| `EQUITY` / `ETF` / `STOCK_FUND` | Ações |
| Nome com AMERICAN(A), GLOBAL, S&P, NASDAQ… ou `OFFSHORE_FUND`/`BDR` | Exterior |
| `FIXED_INCOME`, demais fundos | Renda fixa |

- **Valor atual:** `balance` informado pela instituição.
- **Investido / preço médio:** `amountOriginal` (e `amountOriginal ÷ quantity` nas ações).
- **Ações:** o Open Finance costuma vir com o preço do dia anterior, então o app atualiza pela cotação da **brapi.dev**.
- A meta **Reserva de emergência** soma automaticamente tudo que é **renda fixa**.

## 3. Cotações das ações: brapi.dev (grátis)

1. Crie conta em **https://brapi.dev** → **Dashboard → criar chave**. O plano gratuito tem 15 mil requisições/mês, 1 ativo por requisição e atualização a cada 30 min.
2. Coloque em `BRAPI_TOKEN`. Sem token, as ações ficam com o preço do Open Finance.
3. Consumo estimado: menos de ~6 mil requisições/mês, por causa do cache de 30 min.
